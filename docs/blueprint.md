# **App Name**: HomeVisitHero

## Core Features:

- Login Authentication: Secure login page for case therapists and clerks.
- Case Dashboard: Home page with 'My Cases' and 'All Cases' tabs, displaying relevant case information.
- New Case Form (Therapist): Form for therapists to input initial case details: therapist names, contact info, patient info, and expected arrival time.
- Case Update Form (Clerk): Form for clerks to add leaving time and expected arrival time. Provides a button for submission that moves the case to 'To be completed by clerk/buddy OT' status.
- Case Closure (Clerk/Buddy Therapist): Allows clerks or buddy therapists to enter the case closing time, which completes the case.
- Status Tracking: Real-time case status updates (e.g., 'To be completed by clerk', 'Complete') visible to all users.

## Style Guidelines:

- Primary color: Light desaturated blue (#ADD8E6) to evoke a sense of calm and security.
- Background color: Very light desaturated blue (#F0F8FF) to create a clean and professional look.
- Accent color: A contrasting darker blue (#4682B4) will be used for interactive elements like buttons and links, for visibility and emphasis.
- Body and headline font: 'PT Sans' (sans-serif) to provide a modern yet approachable aesthetic, ensuring readability and ease of use throughout the platform.
- Clean, intuitive layout with clear visual hierarchy to ensure ease of navigation and quick access to key information.
- Use clear and professional icons to represent different case statuses and actions.
- Subtle transitions and animations for a smooth and engaging user experience when navigating between pages and submitting forms.
